# Implementation playbook

## Phases
1. **Discover** — map the real workflow, owners, systems of record, failure modes.
2. **Bound** — write system boundaries, non-goals, data classes, approval points.
3. **Design** — architecture with eval hooks and audit log from day one.
4. **Build** — smallest useful loop; deterministic gates before agent autonomy.
5. **Evaluate** — regression set, human review samples, false-done tests.
6. **Deploy** — staged rollout, rollback path, observability.
7. **Handoff** — runbooks, ownership, templates the customer team can operate.

## Artifacts produced each engagement
- Discovery notes → buildable scope
- Architecture one-pager
- Eval plan + acceptance criteria
- Go-live checklist
- ProofPacket or equivalent evidence bundle
